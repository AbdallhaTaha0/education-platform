## Changes implemented

- Public home, catalog, published course, available package and support documents have Arabic/English paths. Existing business APIs and exactly STUDENT/ADMIN remain unchanged.
- Shared pageMetadata supplies initial and browser title/description/robots/canonical, OG/Twitter and truthful JSON-LD. Course/package descriptions combine actual translated title with actual description. Page 2 has its own identity; unknown filters/page-size variants are not promoted as indexable pages.
- Generated robots/sitemap use a validated explicit HTTPS origin. Publication/deletion and package availability gates use existing public serializers. Errors and private browser routes remove canonical/schema; backend responses default noindex until a valid public renderer deliberately enables them.
- Nginx local and Railway templates proxy HTML/discovery to this same backend, retain API/socket/JWKS behavior, serve hashed assets/icons, compress eligible public text/static resources, preserve frame restrictions and block API aliases to the internal renderer.
- Course cards, header/dock/footer, language switch, package members and pagination use native public links. Course/package breadcrumbs visibly match JSON-LD.
- Thirteen private route components are lazy-loaded. Public seed data avoids redundant initial API fetches; home bootstrap contains three courses. No authentication tokens were moved to storage.
- Hero keeps responsive WebP/dimensions/decorative alt, eager loading and high fetch priority. Header accessible names match visible labels. Stable stacked breadcrumbs avoid a font-induced line collapse. Shared hydration preserves server content and saved themes.
- Docker images include private bundled SSR code in the server only; static frontend has browser assets only. No SEO dependency or database migration was added.

## Remaining recommendations

Review every real published course/package translation, title and description for usefulness and actual curriculum coverage. Duplicate owner-authored names may still yield duplicate metadata; the system does not invent replacements. Adopt real legal policies only after owner review; their current placeholders remain excluded.

Profile mobile LCP on the deployed host. Existing self-hosted swap fonts preserve brand typography but still cost several requests; assess measured critical font hints/fallback metrics before changing them. Further public/private splitting is optional after profiling. Existing whole-catalog DTO and 100-package list behavior need a separate bounded scale change if the catalog grows. Above 50,000 sitemap URLs the renderer deliberately refuses an invalid oversized sitemap; add a real index before reaching that size.

## Indexability improvements

Public content has normal independent paths and meaningful initial HTML. Search controls default to disabled with an explicit configured-origin gate. Only PUBLISHED/nondeleting courses and available packages enter sitemap. Missing/draft/deleting course routes 404; unavailable package pages retain useful availability information but noindex. Dependency/renderer failures 503. Authentication/entitlement controls remain authoritative; robots is not access control.

Private pages are fragment application states and are not sitemap documents; initial HTTP requests cannot distinguish a fragment. SSR always exports only anonymous public DTOs, private APIs are protected/noindex, and browser transitions remove public canonicals/schema and set noindex. No bare /admin or private pathname is made public.
